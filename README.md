# CIROP - Customer Intelligence & Revenue Optimization Platform

Enterprise analytics platform combining customer segmentation, CLV prediction, churn prediction, revenue forecasting, and executive decision support.

## Tech Stack
- **Frontend:** React + Redux Toolkit + Tailwind CSS
- **Backend:** Node.js + Express + Prisma
- **Database:** PostgreSQL
- **ML:** Python + FastAPI + scikit-learn + XGBoost + Prophet
- **Streaming:** Redpanda
- **MLOps:** MLflow + Evidently + Prefect
- **Infrastructure:** Docker + Docker Compose

## Quick Start

docker-compose up -d
